MAINCRAFTS AI/ML INTERNSHIP - TASK 1
====================================

Files:
1. task1_ml_linear_regression.ipynb
2. Task1_Linear_Regression_Report.pdf
3. requirements.txt

How to run:
-----------
1. Install Python 3.x.
2. Open a terminal in this folder.
3. Create a virtual environment:
   python -m venv venv

4. Activate it on Windows:
   venv\Scripts\activate

5. Install packages:
   pip install -r requirements.txt

6. Start Jupyter:
   jupyter notebook

7. Open:
   task1_ml_linear_regression.ipynb

8. Run all cells from top to bottom.

9. Confirm the printed MAE, RMSE and R² values.

10. Submit the notebook and PDF report according to the internship instructions.

Expected reference metrics for the standard 80/20 split (random_state=42):
MAE  = 0.5332
RMSE = 0.7456
R²   = 0.5758

IMPORTANT:
Run the notebook before submission. The notebook itself calculates the final metrics.
