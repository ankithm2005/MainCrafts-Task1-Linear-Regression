# MainCrafts AI & ML Internship – Task 1

## California Housing Price Prediction using Linear Regression

This project was completed as part of the MainCrafts Technology Artificial Intelligence & Machine Learning Internship.

## Objective

Build and evaluate a Linear Regression model to predict California house prices using the California Housing dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Load the California Housing dataset
2. Perform Exploratory Data Analysis (EDA)
3. Check missing values
4. Analyze feature correlations
5. Split the dataset into training and testing sets
6. Train a Linear Regression model
7. Make predictions
8. Evaluate using MAE, RMSE and R²
9. Visualize actual vs predicted values
10. Perform residual analysis
11. Save the trained model

## Dataset

California Housing dataset provided through scikit-learn.

## Model

Linear Regression

## Evaluation

The notebook contains the final MAE, RMSE and R² values obtained from the model.
